# Agent 选型

## 定义
选择适合自己公司情况的 AI Agent（如 Codex、Claude Code、WorkBuddy）的决策过程。核心考量：网络环境、使用场景、成本预算。

## 关键要点

### 决策树
```
能不能稳定访问境外服务？
├── 能 → 有没有特别偏好？
│   ├── 有 → 选偏好产品
│   └── 没有 → 选 Codex
└── 不能 → 直接选国内产品（如 WorkBuddy）
```

### 三个选项对比
| 选项 | 优势 | 风险 |
|------|------|------|
| Claude Code | 能力天花板最高 | 封号风险高 |
| Codex | 综合体验好 | 需要境外访问 |
| WorkBuddy | 零障碍、中文友好 | 英文能力有限 |

### 选型原则
1. **先把 AI 用起来，比用什么 AI 重要一百倍**
2. 别纠结，纠结的代价远大于选错的代价
3. 半年后可能都会换，先跑起来再说

### 成本三阶段
1. **订阅额度**：月费固定，适合初期
2. **国内模型接入**：成本可控，适合稳定期
3. **私有化部署**：长期最便宜，适合成熟期
