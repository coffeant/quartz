# Framework: AARRR-Metrics

## 概述

**AARRR（海盗指标）** 是衡量用户全生命周期增长的经典框架，由 Dave McClure 提出。它将用户旅程分为五个阶段，每个阶段有对应的北极星指标。

## 框架结构

```
Acquisition（获客） → 用户从哪里来
      ↓
Activation（激活） → 用户是否体验到核心价值
      ↓
Retention（留存） → 用户是否持续回来
      ↓
Revenue（收入） → 用户是否愿意付费
      ↓
Referral（推荐） → 用户是否推荐给别人
```

## 关键指标

| 阶段 | 核心指标 | 示例 |
|------|---------|------|
| Acquisition | CAC、渠道转化率 | 自然搜索占比、广告 CPC |
| Activation | 激活率、Time-to-Value | 注册→首次使用核心功能 |
| Retention | DAU/MAU、Churn Rate | 7日留存、月流失率 |
| Revenue | ARPU、LTV、Payback Period | 付费转化率、客单价 |
| Referral | NPS、病毒系数 | 推荐转化率、邀请人数 |

## 应用场景

- 用于发现增长瓶颈：哪个阶段的转化率最低？
- 用于对齐团队认知：产品、营销、销售看同一套指标
- 用于设定 OKR：每个阶段设定一个关键指标
