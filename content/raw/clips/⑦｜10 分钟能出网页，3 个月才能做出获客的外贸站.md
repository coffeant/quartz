## 开篇：我用一句话做了个算命网站

先讲个现场的小插曲。

中场休息前，我随口让 AI 做了个东西：输入生日时辰，生成八字命盘、四柱排盘、大运流年、可视化报告。

**它真做出来了。** 一个完整的网页，当场在浏览器里打开，左边是命盘，右边是分析，还给了"最近月份宜立文书谈判、下半年如何如何"这种内容。

全场笑。

然后我说了一句： **"这就是个网站。"**

它的源代码就在我本地的一个文件夹里。你把它拷出来、找个空间传上去、绑个域名，它就能被访问了。你给它起个名字叫"我的命盘"，别人一搜就能查到—— **上线了。**

**做网页这件事，现在就是这么简单。**

但紧接着我必须说另一句话，这句话才是我真正想讲的：

> **如果你要做一个真能获客的网站，这还远远不够。**

## 一、"AI 建站"到底简单在哪

先看最简单的路径，三步：

**1\. 给它一份素材。**

公司的宣传 PDF 就行——这个你总有吧，不然连展都没法参。

**2\. 说一句话。**

> 根据这个文件帮我做一个网页。需要图片的话，从 PDF 里自己截，或者网上自己找。做好之后试一下没问题告诉我。

**3\. 完事。**

它做完会自己打开给你看。

如果你想再简单一点，我们做了个免费的入口（在 xpyseo.com Logo 旁边有个"AI 免费建站"），地址是 https://xpyseo.com/freesite/，你把阿里店铺地址、或者公司 PDF、或者现有网站传上去，它自己分析、自己提取有价值的信息、自己生成网页。 **除了域名钱，其他都免费。**

这个网站是有真实询盘的——最早是帮一个学员临时做的，我想反正折腾一通，干脆做成所有人都能用的。

**但请注意它的定位：这是个"够用"的网站，不是"能打"的网站。**

## 二、为什么"能打开"和"能获客"差这么远

我听到客户说得最多的一句话是：

> "AI 都来了，你们做个网站怎么还这么麻烦？我就想三五天做完！"

最后做了三五个月。

**因为网站的细节，多得超出想象。**

我在现场列了三大类 Skill，你就明白"做个好网站"到底要处理多少事：

![Image](https://mmbiz.qpic.cn/sz_mmbiz_png/W5ZZ9EHB0lyxo9dibQV7tuahD3SRMRtpIDPF2Oao4bug389R0tqh1kA6iay7RCt1WDTKCGpIVpBRYFaLOb1fV8lOpWicussYtjvIeu5u6s7gJE/640?wx_fmt=png&from=appmsg#imgIndex=0)

### 第一类：设计（解决"一眼假"）

AI 做出来的东西，很多人一眼能看出来是 AI 做的。怎么让它有品味？

- **设计品味**
	：这是第一位的能力
- **UI/UX 模板库**
	：让 AI 在成熟模板里调，而不是从零瞎造
- **配色规范**
	：比如你 logo 是橙色，相关配色都得跟橙色搭起来，别突然来个大红大绿
- **前端布局**
- **高级感打磨**
	：摄影风格、苹果风格、精细排版
- **动效库**
	：进网站看到的各种动态效果
- **UI 组件库**
	：按钮、卡片这些组件化的东西

### 第二类：转化（这才是重点）

![Image](https://mmbiz.qpic.cn/mmbiz_png/W5ZZ9EHB0ly2WNhcsryGAvzSiaUJC0dUE7B91PlRK8KiaBHxicBgXtH7wTDlcX1PiaVfnOtC3dFHLLJGalmK4jw0q5voFarLrtScsbDkic9ggte4/640?wx_fmt=png&from=appmsg#imgIndex=2)

**你做网站不是为了"有个网站"，是为了让客户愿意留联系方式。**

- 表单怎么设计
- 落地页怎么设计
- 信任元素怎么表达更容易被信任
- 文案怎么写更有说服力
- Offer 怎么设计（赠品、保证、限时）
- 弹窗怎么设计
- 注册与转化路径
- A/B Test 怎么做

### 第三类：内容（决定质量的根本）

回到第 4 篇那个对比： **同样一句"帮我做个网站"，接不接知识库，出来完全是两个东西。**

因为只给它一个 PDF，它对你公司的了解就只有那一个 PDF。

## 三、三条验收标准（这是本篇最实用的部分）

![Image](https://mmbiz.qpic.cn/sz_mmbiz_png/W5ZZ9EHB0lyIibeZPcVuZ9pQvVFgayNgxArbZy4V15bw3Pl1EqZFeJ7dEvchBPygwfy9Hb7DpRU4FsUYiaKx7eqFnrW3WufglMlW7GNn2qhVE/640?from=appmsg#imgIndex=3)

网站做完了，到底行不行？别凭感觉，用这三条：

### 标准一：有源代码

WordPress 做的网站你有源代码；用 AI 做的， **代码就在你电脑上** ，因为 AI 就是你的后台。

为什么这条重要？ **没有源代码，你就不拥有这个网站。**

### 标准二：你觉得好看

这条看着主观，其实很关键——因为你最了解你的客户。

它要能传递你想传递的东西，要有利于转化。

### 标准三：PageSpeed 评分（这条是硬的）

SEO 到底行不行，不是你说行、我说行， **Google 有官方标准** 。

工具就是 Google 出的 PageSpeed（免费的，输个网址跑一两分钟出分）。

**我们自己的要求：**

| 端 | 及格线 |
| --- | --- |
| 桌面端 | **90 分以上** |
| 移动端 | **70 分以上** |

为什么移动端低一些？因为外贸网站基本都是响应式的，桌面端分高的时候，移动端渲染速度天然会低一些。

⚠️ **重点在于：你不用自己去调这些分。**

那些建站 Skill 里已经写了这条要求。你只要告诉它"我要建站，PageSpeed 桌面 90、移动 70"， **它达不到就自己修、自己调，直到达标** 。

这就是我前面说的"人管标准，AI 管执行"。

## 四、表单：没有后台的网站怎么收询盘

AI 做出来的网站是静态的，没有后台。那客户提交的表单去哪了？

**用一个免费的表单 API：Web3Forms。**

做法：

1. 去注册一个 Web3Forms 账号；
2. 它会生成一个 API 接口；
3. 把这个 API 扔给你的 AI，说"我表单通过它发到我邮箱"；
4. 完事。

客户一提交表单， **邮件直接到你邮箱** ，你就能收到询盘了。

⚠️ 这又是一个"有 API 就有一切"的例子。顺便复习一下那个成本对比：

> **有 API：AI 直接通信，又快又省。**
> 
> **没 API：AI 只能"肉眼看"界面再点击操作，token 消耗大约是一百倍** （现场口径）。

所以我的原则再重复一遍： **选线上工具，第一个问题永远是"有 API 吗"，没有就换。**

## 五、一个必须知道的现实：AI 就是后台

这里有个很关键、但很多人没意识到的点：

**AI 建的网站，没有后台管理系统。AI 就是它的后台。**

这意味着什么？

### 对你自己：效率极高

你要改个东西，在原来那个对话里说一声就行：

> 在这个页面后面加上"鑫海"两个字。

它自己就去改了。 **因为它记得前面聊了什么、这个网站是怎么建起来的。**

这就是"一人闭环"的典型场景： **你做、你维护、你的 AI 全包了，效率极高。**

### 对交付给别人：基本不可行

如果你想把这个网站交给同事维护—— **难了。**

因为他得重新了解：这个网站是什么、服务器怎么连的、授权是怎么建立的、之前聊过什么……一堆上下文要重学一遍。

而且他学不会的时候会来问你， **而你可能自己都答不上来——因为建站过程都是 AI 干的。**

⚠️ 这也是为什么我说： **这种网站适合一人闭环，不适合团队协作交付。**

### 关于 WordPress

课间有人问：能不能让 AI 直接在 WordPress 后台里建站？

我的答案是： **维护可以，建不行。**

原因很具体：页面上这个字，在 WordPress 后台对应哪个字段、哪个模块—— **这个映射关系，AI 没法自动解决** 。

我试过。最后的结果是：它套进去的准确性很差，最后还得人去改。而一般人 **都不愿意接手半拉子工程** ——接半拉子还不如重写。

**所以现阶段：WordPress 建站，还是得人来做。**

## 六、站群 vs 主站：这是两种完全不同的玩法

![Image](https://mmbiz.qpic.cn/sz_mmbiz_png/W5ZZ9EHB0lzxGoOduFZ5TOfwzsDlYNXic0nAchrxTC6iauKP8PuZiceSbqgWqEQibSKWDYjrT6GIy86gWnPMr5AiclKJqeDUXP0IX5KnyGGqM2PE/640?from=appmsg#imgIndex=4)

这是我被问得最多、也最想讲清楚的一节。

### 主站：安全 > 效果

**主站就是你印在名片上的那个网站。**

它的核心作用不是带来泛流量，而是 **兜住你的品牌流量** ：

- 客户在阿里上看到你，回头搜你公司名；
- 客户在展会上拿到你名片，回头搜你公司名；
- 客户在别的地方听说过你，回头搜你公司名。

**客户可能记不住你的网址，但他记得住你公司名。**

这时候你的独立站，是承接你所有其他渠道投入的那个容器。

⚠️ **所以主站一旦出事，你前面在阿里、在展会、在广告上花的钱，全都白花。**

**主站的原则：安全大于效果。**

### 站群：可以试错

站群是另一套逻辑。

成本就是：一个域名（约 60 元/年）+ 一点空间 + 一点 token。 **成本极低。**

这带来一个很爽的心态：

> **只要它在挂掉之前带来一两个客户，就值了。** 挂了就挂了，再做。

这不是我拍脑袋说的。早些年我们做站群， **高峰期网上同时活着两三千个网站** ，每人每天的工作就是上线两个网站——上午一个、下午一个。

网站很快会死，但在它活着的那段时间里， **服务器和域名的成本早就赚回来了** 。

**B2B 就是这样，来一个客户就回本了。**

### ⚠️ 一条最重要的红线

把这两件事连起来，就是全场最重要的一句话：

> **AI 自动生成、未经人工修改的内容，绝对不要发到主站上。**
> 
> **内容发到线上前的最后一步一定是「人工修改」。**

原因在第 8 篇详细讲（AI 标识与 AI 度）。这里先给结论：

- **主站**
	：按标准流程做内容 → **人工检查修改** → 降低 AI 度 → 安全，但慢；
- **站群**
	：AI 自动做 → 大量发 → 死了就死了。

**老站要稳稳当当做，新站（站群）可以放开试。**

这也是为什么"AI 建站"这件事，对不同的人意义完全不同：

| 你的情况 | 建议 |
| --- | --- |
| 只有一个主站，靠它兜品牌流量 | **稳着做**  ，内容人工把关 |
| 想快速试一批词、试一批市场 | **多注册域名**  ，AI 做站群，控制成本 |
| 想要个简单的展示页 | 用免费工具生成，绑个域名就上线 |

## 本篇清单

- AI 建站的最简路径： **给 PDF → 说一句话 → 出网页 → 传空间绑域名**
- 想做得好，靠两类 Skill： **设计类** （品味/模板/配色/动效）+ **转化类** （表单/落地页/信任/文案/offer/A-B）
- 验收三条： **有源代码 + 你觉得好看 + PageSpeed 桌面 90 / 移动 70**
- 表单收询盘： **Web3Forms** 免费 API
- ⚠️ **AI 就是后台** ：自己维护极高效，交付给别人基本不可行
- ⚠️ WordPress： **维护可以，AI 直接建不行**
- ⚠️ **主站 = 安全优先** （兜品牌流量）； **站群 = 可试错** （成本极低，来一单就回本）
- ⚠️ **AI 生成的未修改内容，绝不发主站**
